# Voice Power

Word-recognition practice: say the word out loud and the browser checks if it recognises it. Or type it instead. 40 words in 3 levels with Arabic meanings.

A free English learning game for students and teachers. No install, no tracking, one HTML file.

## Play
Open `index.html` in a browser (Chrome or Edge recommended for speech features), or enable GitHub Pages for this repo.

## Customize
Open `index.html` and edit the word or question list at the top of the script. Teachers are welcome to adapt it for their classes.

## Contribute
Pull requests with new questions, levels or translations are welcome.
